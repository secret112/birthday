# Two Days of Magic 🎂✨

A responsive HTML/CSS/JS birthday website for Manu (19 September) and Sonu (20 September, turning 8).

## Run
Open `index.html` in Chrome/Edge/Samsung Internet.

## Add Sonu's video
Put your own video at:

`assets/sonu-video.mp4`

The site does not include copyrighted Barbie/Doraemon images. The design uses cute original emoji/decorative elements instead. You can replace the character cards with images you have permission to use.

## Voice
The site uses the browser's built-in speech synthesis. On some Samsung/Realme phones, the voice depends on the installed TTS engine and browser settings. For a guaranteed cute voice, replace this with an MP3 in `assets/` and play it after a user tap.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders.
3. Settings → Pages → deploy from the `main` branch.
4. Open the generated GitHub Pages URL on mobile or laptop.
